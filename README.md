# Сайт работы «Частота»

## Что положить в папки
- `assets/video/chastota.mp4` — главное видео (на главной странице)
- `assets/video/poster.jpg` — обложка видео (необязательно)
- `assets/gallery/` — фото и видео с форума
  и впишите их имена в `js/media.js`

## Публикация на GitHub Pages
1. Создайте репозиторий на github.com, загрузите в него ВСЁ содержимое этой папки (index.html должен лежать в корне репозитория).
2. Settings → Pages → Source: «Deploy from a branch», ветка `main`, папка `/ (root)` → Save.
3. Через 1–2 минуты сайт откроется по адресу `https://ваш-логин.github.io/название-репозитория/`

## Важно
- Файл на GitHub не больше 100 МБ (через веб-интерфейс — не больше 25 МБ). Большие видео загружайте через GitHub Desktop или git, либо сожмите (HandBrake, H.264 MP4).
- Имена файлов лучше писать латиницей без пробелов.
